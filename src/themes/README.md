# 🎨 Темы оформления

Оформление проекта полностью вынесено из компонентов. Здесь описано, **как
добавить свою тему за пять минут** и почему система устроена именно так.

---

## Главная идея: роли вместо цветов

Компоненты **не знают** ни одного конкретного цвета. Они говорят ролями:

```tsx
// ❌ Так НЕ пишут: цвет зашит в компонент
<div className="text-[#e8b53f] bg-[#0e1422]">

// ✅ Так пишут: указана РОЛЬ, а цвет подставит тема
<div className="text-accent bg-surface">
```

Ролей всего двенадцать, и у каждой — своё назначение:

| Токен | Роль | Утилиты Tailwind |
| --- | --- | --- |
| `canvas` | фон страницы | `bg-canvas` |
| `surface` | фон панелей | `bg-surface` |
| `surface-2` | вложенные блоки, дорожки ползунков | `bg-surface-2` |
| `ink` | **основной текст — читать** | `text-ink` |
| `ink-muted` | второстепенный текст, подписи | `text-ink-muted` |
| `ink-faint` | служебный текст: нумерация, подсказки | `text-ink-faint` |
| `line` | обычные рамки | `border-line` |
| `line-strong` | заметные рамки | `border-line-strong` |
| `accent` | **главное действие — нажимать** | `text-accent`, `bg-accent`, `border-accent` |
| `accent-2` | предупреждение, важное | `text-accent-2` |
| `accent-3` | ссылки, служебные акценты | `text-accent-3` |
| `alert` | ошибки, удаление | `text-alert`, `border-alert` |
| `on-accent` | текст поверх акцентного фона | `text-on-accent` |

### Вторая половина темы: ФОРМА

Цветами дело не ограничивается. Тема может менять сам **характер**
интерфейса — это вторая группа параметров:

| Переменная | Что делает | Ноль означает |
| --- | --- | --- |
| `--radius-panel` | скругление панелей | прямые углы |
| `--radius-control` | скругление кнопок и полей | прямые углы |
| `--corner-size` | размер декоративных уголков | уголки исчезают |
| `--scanline-alpha` | плотность полос развёртки | ЭЛТ-эффект выключен |
| `--vignette-alpha` | затемнение по краям | виньетка выключена |
| `--glow-alpha` | сила свечения текста | свечения нет |
| `--motif-opacity` | прозрачность орнаментов | орнаменты не видны |

Именно благодаря им существует светлая тема `alexandria`: она выключает
ЭЛТ-эффекты (`--scanline-alpha: 0`), скругляет углы (`--radius-panel: 8px`)
и гасит свечение (`--glow-alpha: 0`). Компоненты при этом не меняются —
это и есть проверка архитектуры: тему можно поменять до неузнаваемости,
правя один CSS-файл.

**Правило, которое нельзя нарушать:** цвета из группы `line` — только для
рамок. Никогда для текста. Именно на этом сломалась первая версия оформления:
подсказка по горячим клавишам была окрашена в цвет рамки, и контраст вышел
1.3:1 (текст практически невидим). Для текста есть три уровня `ink`.

## Структура папки

```
src/themes/
├── registry.ts     реестр тем: id, название, описание, цвета для превью
├── aegean.css      тема «Эгейское море» (по умолчанию)
├── oracle.css      тема «Дельфийский оракул»
├── gibson.css      тема «Гибсон»
├── alexandria.css  тема «Александрийская библиотека» (СВЕТЛАЯ)
└── README.md       этот файл
```

Плюс два файла вне папки:

* `src/app/globals.css` — объявляет токены (блок `@theme`) и структурные
  классы (`.term-panel`, `.term-btn`, …). Цветов здесь нет, только роли.
* `src/config/branding.ts` — имя проекта, слоганы, тексты. Тоже в одном месте.

## Как добавить свою тему

### Шаг 1. Создать CSS-файл

`src/themes/mytheme.css`:

```css
html[data-theme="mytheme"] {
  /* Фоны */
  --color-canvas: #0a0a12;
  --color-surface: #12121c;
  --color-surface-2: #1c1c2a;

  /* Текст: три уровня важности, ВСЕ обязаны быть читаемыми */
  --color-ink: #f0f0f5;
  --color-ink-muted: #b8b8c8;
  --color-ink-faint: #9090a4;

  /* Рамки */
  --color-line: #2a2a3c;
  --color-line-strong: #454564;

  /* Акценты */
  --color-accent: #7c6cff;
  --color-accent-2: #ff6c9c;
  --color-accent-3: #4fd1c5;
  --color-alert: #ff5f52;
  --color-on-accent: #0a0a12;

  /* Необязательные декоративные параметры */
  --scanline-alpha: 0.18;  /* плотность полос развёртки */
  --vignette-alpha: 0.5;   /* затемнение по краям */
  --corner-size: 12px;     /* размер уголков у панелей */
  --glow-alpha: 0.35;      /* сила свечения заголовков */
}
```

### Шаг 2. Подключить файл

В `src/app/globals.css`, рядом с остальными темами:

```css
@import "../themes/aegean.css";
@import "../themes/oracle.css";
@import "../themes/gibson.css";
@import "../themes/mytheme.css";   /* ← добавить */
```

### Шаг 3. Зарегистрировать

В `src/themes/registry.ts`:

```ts
export type ThemeId = "aegean" | "oracle" | "gibson" | "mytheme";   // ← добавить

export const THEMES: readonly ThemeDefinition[] = [
  // …существующие темы…
  {
    id: "mytheme",
    label: "МОЯ ТЕМА",
    greekLabel: "ΙΔΙΑ",              // подпись греческими буквами
    description: "Одна строка: чем эта тема отличается.",
    swatches: ["#0a0a12", "#7c6cff", "#f0f0f5"],  // фон, акцент, текст
  },
];
```

Готово. Тема появится в переключателе в боковой панели.

### Шаг 4. Проверить контраст

Обязательно, а не «на глаз». Требование WCAG AA — **4.5:1** для обычного
текста. Посчитать можно так:

```bash
bun -e '
const lum = (h) => { const [r,g,b] = [1,3,5].map(i => { const c = parseInt(h.slice(i,i+2),16)/255; return c <= 0.03928 ? c/12.92 : ((c+0.055)/1.055)**2.4; }); return 0.2126*r+0.7152*g+0.0722*b; };
const ratio = (a,b) => { const [x,y] = [lum(a), lum(b)].sort((m,n)=>n-m); return ((x+0.05)/(y+0.05)).toFixed(2); };
console.log("ink   к фону:", ratio("#f0f0f5", "#0a0a12"));
console.log("faint к фону:", ratio("#9090a4", "#0a0a12"));
'
```

Если `faint` даёт меньше 4.5 — осветли его. Именно этот тест провалила
первая версия оформления.

## Как тема попадает на страницу

Полный путь от клика до нового цвета:

```
1. Пользователь жмёт тему в боковой панели
      └─ ThemeSwitcher: setState(newTheme)

2. useEffect синхронизирует состояние с внешним миром:
      ├─ document.documentElement.dataset.theme = newTheme   ← мгновенно
      └─ document.cookie = "orpheus_theme=newTheme; …"       ← на будущее

3. Браузер видит новый атрибут <html data-theme="mytheme">
      └─ все CSS-переменные пересчитываются
      └─ все утилиты (text-ink, bg-surface…) получают новые значения
      └─ НИ ОДИН React-компонент не перерисовывается

4. При следующей загрузке страницы:
      └─ сервер (src/app/layout.tsx) читает cookie
      └─ рендерит <html data-theme="mytheme"> СРАЗУ
      └─ вспышки чужого оформления не происходит
```

### Почему cookie, а не localStorage

Это ключевое решение, и вот его причина. Страница рендерится на **сервере**,
и сервер должен сразу вставить правильный `data-theme` в HTML.

`localStorage` серверу недоступен — это API браузера. Если хранить тему там,
получится так: сервер отдаст тему по умолчанию → браузер выполнит JavaScript
→ прочитает localStorage → переключит тему. Пользователь увидит **вспышку
неправильных цветов** (FOUC, flash of unstyled content). А если React успеет
отрисовать разметку до переключения — ещё и ошибку гидратации.

Cookie приходит на сервер вместе с каждым запросом, поэтому проблема исчезает.

> **Правило на будущее:** всё, что влияет на серверный рендеринг, храни
> в cookie, а не в localStorage. В localStorage — только то, что нужно
> исключительно браузеру (громкость плеера, например).

### Почему смена темы мгновенная

Тема — это не данные React, а **значения CSS-переменных**. Компоненты
ссылаются на переменные через утилиты (`text-ink` → `color: var(--color-ink)`).
Поменялся атрибут на `<html>` → браузер пересчитал переменные → стили
обновились. React в этом не участвует вообще, поэтому переключение
происходит за один кадр, независимо от размера списка треков.

## Доступные CSS-классы

Структурные классы объявлены в `src/app/globals.css` и тоже используют
только роли, поэтому автоматически подходят любой теме:

| Класс | Назначение |
| --- | --- |
| `term-panel` | панель: фон `surface`, рамка, декоративные уголки |
| `term-title` | заголовок панели: акцентный, капс, свечение |
| `term-btn` | кнопка с инверсией при наведении |
| `term-btn-danger` | кнопка опасного действия (удаление) |
| `term-btn-active` | выбранное состояние кнопки |
| `term-input` | поле ввода |
| `track-row` | строка трека (состояние — через `data-playing="true"`) |
| `term-range` | ползунок (перемотка, громкость) |
| `cursor-blink` | мигающий курсор |
| `glow` | свечение текста |
| `ascii-rule` | разделитель из символов |
| `motif-meander` | **полоса греческого меандра** |
| `motif-frieze` | **дорический фриз** |
| `fade-up` | короткое появление блока |

### Про орнаменты

`motif-meander` — самый интересный класс. Это греческий ключ (меандр),
сделанный **без единой картинки**:

```css
.motif-meander {
  height: 12px;
  background-color: currentColor;          /* цвет берётся из класса text-* */
  mask-image: url("data:image/svg+xml,…"); /* SVG-контур работает как трафарет */
  mask-repeat: repeat-x;
}
```

SVG вшит прямо в CSS как data-URI и работает **маской** (по прозрачности),
а не картинкой. Цвет задаётся через `background-color: currentColor` — то есть
родительским классом `text-accent` или `text-line-strong`.

Почему это правильное решение: обычная картинка имела бы зашитый цвет
и не менялась бы при смене темы. А маска красится чем угодно — одна и та же
плитка работает во всех трёх темах.

Контур не рвётся на стыках: линия заканчивается на правом краю плитки
на той же высоте, где начинается следующая.

## Чек-лист новой темы

- [ ] CSS-файл создан в `src/themes/`
- [ ] Все двенадцать токенов заданы (если пропустить — подставится значение из `@theme`, и тема будет выглядеть «наполовину старой»)
- [ ] `@import` добавлен в `globals.css`
- [ ] Тема зарегистрирована в `registry.ts`
- [ ] Контраст `ink`, `ink-muted`, `ink-faint` к `canvas` ≥ 4.5:1
- [ ] Контраст `on-accent` к `accent` ≥ 4.5:1
- [ ] `accent` заметно отличается от `ink` (акцент не должен выглядеть как текст)
- [ ] Проверено в браузере: **все три темы**, на странице библиотеки, плейлиста и в панели плеера
- [ ] Проверено с включённым `prefers-reduced-motion`

## Чего делать не стоит

| Антипаттерн | Почему плохо |
| --- | --- |
| Хардкод цвета в компоненте (`text-[#e8b53f]`) | тема перестанет на него влиять |
| Использовать `line`/`line-strong` для текста | контраст почти наверняка провалится |
| Хранить тему в `localStorage` | вспышка чужого оформления при загрузке |
| Делать `ink-faint` «на грани видимости» | именно так и появилась нечитаемая подсказка по клавишам |
| Много светящегося текста (`glow` везде) | свечение снижает читаемость, а не повышает |
| Игнорировать `prefers-reduced-motion` | недоступно и опасно для части людей |
